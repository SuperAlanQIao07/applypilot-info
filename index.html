ApplyPilot — Personal Job Application Assistant

ApplyPilot is a personal-use desktop application operated by Yinqi Qiao. This installation is based on the open-source ApplyPilot project and is independently operated; it is not an official service of Google or the upstream project maintainers.

ApplyPilot helps its operator discover job opportunities, prepare factual resumes, manage authorized applications, and track recruiting responses in a private local dashboard.

Gmail integration

With the account holder's authorization, ApplyPilot uses the Gmail API to:

  • Find recent job-related messages and match them to recorded applications.
  • Read relevant message content to identify application receipts, rejections, interview invitations, follow-up requests, and offers.
  • Retrieve legitimate verification codes for the current authorized application and enter them into the same application browser session.

The integration requests only https://www.googleapis.com/auth/gmail.readonly. This permission permits reading Gmail data; it does not permit sending, deleting, modifying, or labeling messages. The application does not request or store the account's Gmail password.

Routine email tracking and verification use deterministic Python rules. Messages without sufficient matching evidence remain unresolved for review.

This installation is intended for the operator's personal use. Application records, resumes, email content, and the private dashboard are not published on this website.
